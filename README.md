# **Netflix Originals Data Analysis**

#### 

#### **Objective:**

The objective of this project is to analyze the Netflix Originals dataset using SQL queries to extract meaningful insights and trends. This project demonstrates the use of SQL operations such as GROUP BY, HAVING, ORDER BY, LIMIT, JOINS, WINDOW FUNCTIONS, and SUBQUERIES for data analysis.



#### **Datasets:**



##### 1\. Netflix\_Originals



&nbsp;  \* Contains information about Netflix Originals including title, genre ID, runtime, IMDb score, language, premiere date.



##### 2\. Genre\_Details



&nbsp;  \* Contains information about genres: Genre ID and Genre Name.



#### **Analyses Performed:**



1\. Average IMDb scores for each genre of Netflix Originals.

2\. Genres with an average IMDb score higher than 7.5.

3\. List of Netflix Original titles in descending order of their IMDb scores.

4\. Top 10 longest Netflix Originals by runtime.

5\. Titles of Netflix Originals along with their respective genres.

6\. Ranking Netflix Originals based on their IMDb scores within each genre.

7\. Netflix Originals with IMDb scores higher than the average IMDb score of all titles.

8\. Count of Netflix Originals in each genre.

9\. Genres with more than 5 Netflix Originals having IMDb scores higher than 8.

10\. Top 3 genres with the highest average IMDb scores and their total Netflix Originals.
